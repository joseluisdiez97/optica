# FASE 11 — Entrega ⏸ → `docs/ENTREGA.md`

Entrega:

1. **Qué has hecho**, en una tabla de antes y después.
2. **Pendiente, sin maquillar**: fotos que no existían, formularios sin servidor,
   textos legales sin redactar, datos que no pudiste confirmar.
3. **Peso** antes y después.
4. **Cómo verlo**: `npx serve .` (o `python3 -m http.server 8080`) y abrir
   `http://localhost:3000` / `:8080`.

## ⏸ PARA AQUÍ

**Pregunta antes de desplegar**, subir a GitHub o tocar cualquier cosa que esté en
producción. Antes de un push, comprueba si hay un proyecto de hosting conectado al
repositorio (Netlify, Vercel, GitHub Pages: `netlify.toml`, `vercel.json`,
`.github/workflows`, `git remote -v`): un push puede publicar sin avisar.
Díselo al usuario explícitamente.
