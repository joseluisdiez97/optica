# Referencias: fuentes, sectores y prohibidos

## Fuentes que funcionan para un agente (en este orden)

**Galerías que enlazan webs reales** (lees la galería, sacas URLs y estudias cada web):

| Fuente | URL | Para qué |
|---|---|---|
| Awwwards | https://www.awwwards.com/websites/ | La que más webs reales enlaza. Premiadas, nivel alto |
| CSS Design Awards | https://www.cssdesignawards.com | Muy buena para animación y efectos |
| One Page Love | https://onepagelove.com | Landings de una sola página |

Búsquedas: `"{sector}" website awwwards`, `"{sector}" site of the day`,
`best {sector} website design`.

**Efectos y animación**: Codrops (https://tympanus.net/codrops/),
GSAP Showcase (https://gsap.com/showcase/).

**Componentes** (React, sirven de idea en vanilla): 21st.dev, ui.aceternity.com.

**Color**: realtimecolors.com, coolors.co.

**No las uses tú** (bloquean agentes o no dan contenido legible). Recomiéndalas al
usuario para mirarlas a ojo: godly.website, siteinspire.com, land-book.com,
lapa.ninja, magicui.design, fontshare.com, mobbin.com.

Si una fuente falla, no reintentes: pasa a la siguiente y anótalo.

## Punto de partida por sector

No es una receta, es un arranque para romperla con criterio:

| Sector | Tiende a pedir | Detalle propio a explotar |
|---|---|---|
| Gimnasio, deporte | Energía, contraste, tipografía enorme | Horario en directo, aforo, cifras de socios |
| Restaurante, bar | Foto, calidez, ritmo de carta | Carta como índice tipográfico, horario de cocina |
| Despacho legal, finanzas | Sobriedad, serif clásica, mucho aire | Colegiación, años, áreas como índice |
| Clínica, salud | Calma, claridad, confianza | Especialidades, cita previa, equipo con credenciales |
| Inmobiliaria | Foto grande, datos limpios | m², precio, zona, en rejilla técnica |
| Estudio creativo | Riesgo tipográfico, retícula rota | Proyectos como archivo numerado |
| Tienda, e-commerce | Producto, rejilla, rapidez | Materiales, tallas, stock |
| Educación, academia | Orden, secuencia, progreso | Temario como proceso numerado |
| Turismo, alojamiento | Lugar, foto, estación | Clima, distancia, temporada |

## Prohibido salvo que el usuario lo pida

Son los diseños que delatan que lo ha hecho una IA:

- Fondo crema (#F4F1EA o parecido) con serif y acento terracota
- Fondo casi negro con un único verde ácido o bermellón
- Degradado morado-azul en el hero
- Inter o Space Grotesk como tipografía "segura"
- Emojis como iconos de sección
- Todo centrado
- Mismo radio y misma sombra en todas las tarjetas
- Numerar secciones 01/02/03 cuando el contenido no es una secuencia
